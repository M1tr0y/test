# Rust3D

Достаёт 3D-модели из игры **Rust** и одной кнопкой отправляет их в **After Effects** и/или **Premiere Pro**.
Внутри работает та же AssetStudio, только без ручного прокликивания.

## Установка

1. Скачай репозиторий: **Code → Download ZIP** и распакуй его в любую папку.
2. Запусти **`install.bat`**. Он поставит Python, если его нет, и создаст ярлык **Rust3D** на рабочем столе.
3. При первом запуске откроется мастер настройки:
   - **Игра**: папка Rust из Steam, находится автоматически. Там же выбирается, куда сохранять модели.
   - **Adobe**: After Effects и Premiere Pro, тоже ищутся автоматически.
   - **Blender**: нужен для Premiere. Бесплатно скачивается с [blender.org](https://www.blender.org/download/).
   - **Установка**: программа сама скачает AssetStudioModCLI и FBX2glTF и поставит панель в Premiere.
4. Сразу после мастера программа один раз прочитает файлы игры и составит список моделей.
   Это долго, несколько минут. Потом список берётся из кэша мгновенно.

## Как пользоваться

1. Введи в поиске название модели, например `ak47`.
2. Кликни по модели в списке.
3. Нажми нужную кнопку:

| Кнопка | Что происходит |
|---|---|
| **After Effects** | Модель с текстурами выгружается, конвертируется в GLB и появляется в композиции AE. Если AE закрыт, он откроется сам. |
| **Premiere Pro** | Blender рендерит видео, где модель вращается на 360° на прозрачном фоне. Видео попадает в папку `Rust3D` в проекте Premiere. |
| **В обе программы** | Делает обе вещи сразу. |
| **Только сохранить** | Кладёт файл `.glb` в папку моделей. |

## Важно знать

- **After Effects**: нужна версия **2024 (24.x) или новее**. Более старые версии 3D-модели не открывают.
- **Premiere Pro** 3D-модели не поддерживает вообще, поэтому туда отправляется видео.
  В первый раз открой панель **Окно → Расширения → Rust3D** (Window → Extensions → Rust3D).
  Пока она открыта, видео импортируются сами.
- Если что-то пошло не так, разверни **Журнал** внизу окна: там видно, на каком шаге произошла ошибка.
- Все настройки меняются кнопкой ⚙ в правом верхнем углу.
- Настройки, скачанные программы и кэш лежат в `%APPDATA%\Rust3D`.

## Сборка в один .exe

После `install.bat` запусти `build_exe.bat`. Получится файл `dist\Rust3D.exe`.

## Как устроено

```
rust3d/core.py      пайплайн: AssetStudioModCLI → FBX2glTF/Blender → AE / Premiere
rust3d/app.py       окно (pywebview), фоновые задачи
ui/                 интерфейс: HTML/CSS/JS
blender/            скрипты Blender: конвертация и рендер вращения
premiere_panel/     CEP-панель, через которую Premiere импортирует видео
```
