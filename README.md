# Rust3D

Панель для **After Effects** и **Premiere Pro**: ищешь модель из **Rust**, жмёшь одну кнопку — она уже в композиции или на таймлайне.
Внутри работает та же AssetStudio, только без ручного прокликивания.

## Установка

1. **Code → Download ZIP**, распакуй (правой кнопкой → «Извлечь всё»).
2. Запусти **`install.bat`** → нажми **«Установить»**. Больше ничего ставить не надо — ни Python, ничего.
3. Открой After Effects или Premiere Pro → **Окно → Расширения → Rust3D**
   (Window → Extensions → Rust3D).

Панель — обычное окно Adobe: её можно таскать за вкладку, пристыковать к интерфейсу или оставить плавающей.
Сама она не открывается — только из меню.

## Как пользоваться

1. При первом открытии панель читает файлы игры. Модели появляются сразу по ходу чтения — ждать конца не нужно.
2. Введи название в поиск (`ak47`, `bradley`…), выбери модель.
3. **В композицию** (AE) или **На таймлайн** (Premiere). Двойной клик и Enter тоже работают.

| Где | Что попадает |
|---|---|
| **After Effects 2024+** | настоящая 3D-модель (GLB) с текстурами в активную композицию |
| **Premiere Pro** | видео с вращением модели на прозрачном фоне (рендерит Blender) — на свободную дорожку под плейхедом |

Модель с галочкой ✓ уже выгружалась — вставится мгновенно.

## Почему быстрее, чем AssetStudio вручную

- файлы игры читаются **в несколько потоков** и только сетки (без текстур, звуков и т.д.);
- список **кэшируется**: после обновления Rust перечитываются только изменившиеся файлы;
- экспорт открывает **только тот файл игры, где лежит модель**, а готовый результат сохраняется.

## Настройки и удаление

- Шестерёнка в панели: папка Rust, Blender, папка моделей, «Перечитать игру» и журнал.
- **`uninstall.bat`** — убирает панель из AE и Premiere (и по желанию скачанные инструменты и кэш).
- Инструменты, настройки, кэш и журнал: `%APPDATA%\Rust3D`. Модели: `Документы\Rust3D`.

## Устройство

```
extension/            CEP-панель (копируется в %APPDATA%\Adobe\CEP\extensions\com.rust3d.panel)
  js/main.js          поиск, параллельное чтение игры, экспорт (Node.js)
  jsx/host.jsx        импорт в AE и Premiere (ExtendScript)
  blender/            конвертация и рендер вращения
installer/install.ps1 окно установщика (PowerShell + WPF)
```
